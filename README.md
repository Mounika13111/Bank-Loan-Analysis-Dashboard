# Bank Loan Analysis Dashboard | Power BI

## Project Overview
This project analyzes bank loan data using Microsoft Power BI to understand loan performance, collections, interest, defaults, and delinquency trends.

## Objectives
- Monitor total loan amount, total loans, total collections, and total interest.
- Analyze default and delinquency rates.
- Identify loan purposes and age groups with higher loan amounts.
- Evaluate loan grades and loan status distribution.
- Track yearly loan trends.
- Compare loan amounts across states.

## Dashboard Features
- **KPI Cards:** Total Loan Amount, Total Collection, Total Interest, Total Loans.
- **Risk Analysis:** Default Loans, Delinquent Loans, Default Loan Rate, Delinquent Loans Rate.
- **Loan Purpose Analysis:** Home Loan, Services, Business, Trade, and Others.
- **Age Analysis:** Loan amounts by age group.
- **Grade Analysis:** Loan amount distribution by loan grade.
- **Trend Analysis:** Year-wise loan amount trends.
- **Loan Status Analysis:** Active, fully paid, charged-off or other loan statuses, as available in the dataset.
- **Geographical Analysis:** State-wise loan amount.

  ## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Insights

- Total collections are approximately 814.90M.
- Total interest is approximately 155.29M.
- The displayed default loan rate is 1.56%.
- The displayed delinquent loan rate is 10.84%.
- Home loans represent the largest purpose category in the displayed chart.
- The year-wise trend reaches its highest displayed value in FY 2019.
